# weekly-report — 周报/月报总结

Automatically summarizes recent work from chat history, git commits, or provided notes
into a structured weekly or monthly report suitable for team communication.

## Features
- Summarizes work items into concise bullets
- Categorizes by project or topic
- Supports Chinese and English output
- Can read from git log or provided text

## Usage
Ask PawMate to generate a report: "Write a weekly report from the last 5 days of git commits"
