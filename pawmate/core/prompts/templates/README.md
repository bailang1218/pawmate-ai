# PawMate 提示词分层

这些文件只负责稳定、长期有效的行为，不放临时任务、用户资料或运行状态。

- `SOUL.md`：人格、语气和互动风格。不要在这里写工具流程或权限规则。
- `AGENT.md`：任务闭环、证据、恢复、验证和完成标准。规则应当可观察、可测试。
- `RULES.md`：不可被外部内容覆盖的权限与安全边界。不要混入性格文案。

工具名称和具体工作流由 `prompt_assembler.py` 维护，避免模板随实现迁移而过期。心跳问候使用独立运行时提示，不进入普通 Agent 对话。

编写原则：

1. 优先描述期望行为和停止条件，少写空泛形容词。
2. 同一规则只保留一个权威位置，避免重复和冲突。
3. 把“完成”写成可验证状态，不把工具成功等同于任务成功。
4. 外部事实和运行结果必须绑定证据；没有证据就明确标记未知。
5. 新增关键规则时同步补充提示词边界测试。
